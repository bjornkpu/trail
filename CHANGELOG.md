## [0.1.0] - 2026-09-28

First release. Scans the git reflogs of every repo under the configured roots and copies each
commit-creating entry (commit, amend, merge, rebase picks, cherry-pick, revert) into a local
SQLite database, so commits erased by squash merges and branch deletion stay on record.
`trail show` lists them by day, `trail search` does full-text search over subjects, bodies and
paths, `--json` feeds them to other tools, `trail backfill` adds older commits from git history,
and `trail install` schedules the scan.
